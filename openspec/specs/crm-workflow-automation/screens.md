# Screens

The flow screens are one set (decision 379, 5 Nov 2026): the canonical boards live under OpenRegister, and an app's flow board is a variant that imports the shared parts with the app's own example flow, step types and wording.

- PqFlow: the flow editor on the canvas with the trigger palette, Keepiq group and ready made templates; variant of the canonical set, imports OrFlowKop, OrFlowPalet, OrFlowCanvas, OrFlowStap https://identity.conduction.nl/screens/board?id=pipelinq/PqFlow
- PqFlowRun: a run on the canvas with the outcome per step; variant of the canonical set, imports OrFlowKop, OrFlowCanvas, OrFlowRunSamenvatting, OrFlowRunStap https://identity.conduction.nl/screens/board?id=pipelinq/PqFlowRun
- PqFlows: the flows overview; variant of the canonical set, imports OrFlowOverzichtTabel https://identity.conduction.nl/screens/board?id=pipelinq/PqFlows
- buildiq/BqFlowsBewerken: the same flow in list mode, opened from buildiq https://identity.conduction.nl/screens/board?id=buildiq/BqFlowsBewerken
- pipelinq/PqLead lead https://identity.conduction.nl/screens/board?id=pipelinq/PqLead
- pipelinq/PqJourneys journeys https://identity.conduction.nl/screens/board?id=pipelinq/PqJourneys
- pipelinq/PqJourney journey https://identity.conduction.nl/screens/board?id=pipelinq/PqJourney
- openregister/OrFlow: the canonical editor these variants follow https://identity.conduction.nl/screens/board?id=openregister/OrFlow
