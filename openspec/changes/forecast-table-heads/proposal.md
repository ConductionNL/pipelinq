# Proposal: forecast-table-heads

## Summary

Board PqForecast draws the quarter table with sortable, filterable heads (a chevron and a funnel per column), the head row 42.5px. The page drew a plain table without them (37.3px). The quarter table becomes a CnDataTable: every column sorts, the owner filters on contains and every figure on a range. The rows are already on the page (one snapshot per owner), so the page sorts and filters them in the browser.
