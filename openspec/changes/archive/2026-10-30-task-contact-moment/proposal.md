# Proposal: task-contact-moment

## Summary

Board PqTaak, Related card: "Gebeld op 6 okt, 10:05 · Oorspronkelijk contactmoment". crmTask schema 1.2.0 adds the optional `contactMoment`, a reference to the ticket (an interaction) the task was created from. The task page's Related widget lists referenced objects already, so the reference shows there without a manifest change.

The follow-up task a logged visit creates now carries the visit's id.
