# Proposal: send-monitor-event-order

## Summary

Board PqVerzendmonitor lists the eight newest events of a mailing, all
stamped 10:02, in the order the deliveries come (a***@ziggo first). The
monitor sorted newest first with a comparison that never answered "equal",
so events of the same moment came out reversed. Events of the same moment
now keep the order they come in.
